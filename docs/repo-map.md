## Interfaces between modules

Modules communicate only through:
1. **SQLite schema** (`src/petmonitor/storage/`) — shared read/write layer
2. **Config files** (`configs/app.yaml`, `configs/dataset.yaml`) — runtime configuration
3. **CLI commands** — agents invoke each other's scripts, never internal functions

No vision code in the Blink adapter. No Blink calls in vision. No storage calls outside storage module.
